# Roadmap

## Phase 1 -- MVP

- User authentication (NextAuth)
- Create and join leagues with invite codes
- View games within a league
- Submit picks (one per user per game)
- Leaderboard showing correct pick counts per league

## Phase 2 -- Enhancements

- Weekly slates (group games into weeks/rounds)
- Pick deadlines (lock picks at game start time)
- Tie-breaker questions
- User profile pages
- League settings (rename, manage members)

## Phase 3 -- Monetization

- Paid / premium leagues
- Premium features (detailed stats, pick history export)
- Ad-supported free tier
